# Fynd

**Discover hackathons. Find opportunities.**

Fynd is an AI-powered hackathon and coding competition discovery platform designed to help students find opportunities from multiple sources in one place.

## What Fynd Does

Fynd aims to simplify hackathon discovery by bringing opportunities together in a searchable, organized platform.

### Current Capabilities

- Public competition discovery and listing.
- Competition search and detail pages.
- Student authentication.
- Organizer event submissions.
- Submission tracking for students.
- Admin review and approval workflow.
- Competition data management.
- Discovery foundations with source adapters.

### Technology Stack

- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Backend:** FastAPI, Python
- **Database:** PostgreSQL
- **ORM:** SQLAlchemy
- **Migrations:** Alembic

### Project Direction

Our current primary focus is expanding the discovery engine to support more authorized sources, improve event extraction, reduce duplicates and verify competition information.

Future plans include allowing organizers to create and host their own hackathons directly on Fynd.

## Development Status

Fynd is actively under development. Features and integrations are being improved incrementally.

## Security

- Never commit `.env` or `.env.local` files.
- Use environment variables for credentials.
- Respect third-party platform permissions and API terms.
- Report security issues privately rather than publishing sensitive information.

## Vision

Make discovering hackathons and coding competitions easier for students by bringing opportunities from across the web into one place.
